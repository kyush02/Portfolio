# 🚀 Kyush Kumar — Developer Portfolio

A modern, fast, and interactive personal portfolio web application built with **React 19**, **Vite**, **WebGL Fluid Animations**, and **Vercel Serverless Email API**.

🌐 **Live Demo:** [kyush-portfolio.vercel.app](https://kyush-portfolio.vercel.app/)

---

## ✨ Features

- **🌐 Live Global Visitor Counter**: Real-time session-locked visitor counter powered by CountAPI.
- **🌊 Interactive Fluid Background**: Responsive WebGL particle fluid simulation reacting to cursor movements.
- **🪢 Interactive Rope Intro**: Physics-driven interactive rope animation for welcoming visitors.
- **🧭 Symmetrical Floating & Mobile Grid Navigation**: Clean floating top navbar for desktop + top-right glassmorphism 2-column menu popup for mobile.
- **👤 About & Education Cards**: Highlighted academic background, university CGPA, and personal overview.
- **🏆 Organic Zigzag Achievements Timeline**: Milestone achievements presented in a connected vertical timeline.
- **📜 Certifications Hub**: Interactive showcase of certificates (Oracle Cloud GenAI, IEI Membership, ATF 2025, Energy Literacy Training).
- **⚙️ Dynamic Skills Matrix**: Categorized tech stack badges (Python, C++, HTML, CSS, Git, VS Code).
- **💻 Featured Projects**: Curated project cards with live links and GitHub repository shortcuts (*MineSafe*, *HTML & CSS Projects*).
- **📄 Resume Modal Viewer**: In-app PDF viewer modal with instant one-click downloading and direct PDF opening.
- **📬 Serverless Contact Form**: Direct email delivery to `kyushkumar@gmail.com` powered by **Resend** and Vercel Serverless Functions.
- **📊 Vercel Analytics & Speed Insights**: Integrated real-time telemetry and Web Vitals monitoring.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/kyush02/Portfolioo.git
cd Portfolioo
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

---

## 🔑 Environment Variables

To enable email delivery via the contact form, set the following variable in your environment or Vercel project settings:

```env
RESEND_API_KEY=your_resend_api_key_here
```
